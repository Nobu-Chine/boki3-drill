# 簿記三級 仕訳ドリル

日商簿記3級の仕訳を、スマホで5問ずつ練習できるドリル。

**公開URL:** https://boki3-drill.vercel.app/

## 出題分野（全8分野・160問）

| 分野 | 問題数 |
|---|---|
| ① 基礎（仕訳の基本） | 20 |
| ② 現金・預金 | 20 |
| ③ 商品売買 | 20 |
| ④ 債権・債務 | 20 |
| ⑤ 固定資産 | 20 |
| ⑥ 資本・税金 | 20 |
| ⑦ 決算整理 | 20 |
| ⑧ 財務諸表（損益振替） | 20 |

## 主な機能

- **5問チャレンジ**: 分野を選ぶと5問出題。借方・貸方の勘定科目を選び、金額を入力して答える
- **苦手分野のおすすめ**: 挑戦済みの分野のうち正答率が80%未満でいちばん低いものをトップに表示
- **間違えた問題を優先出題**: 前に間違えた問題から先に出る
- **解説とAI質問用コピー**: 解答後に解説を表示。問題と解答をまとめてコピーでき、AIにそのまま質問できる
- **共有ボタン**: ホーム画面から開いたときでもURLを友だちに送れる
- **成績の保存**: 成績はブラウザ（localStorage）に保存。ログイン不要

## 使っている技術

- HTML / CSS / JavaScript だけの1ファイル構成（`index.html`）
- ライブラリやビルドは不要
- Vercel（デプロイ）

## ローカルで動かす

`index.html` をブラウザで開くだけで動く。

共有ボタンなど一部の機能はサーバー経由で開く必要があるので、確認するときは簡易サーバーを使う。

```bash
python -m http.server 5173
```

http://localhost:5173 を開く。

## 問題の追加・修正

`index.html` の `CATEGORIES`（`<script>` の先頭）に、分野ごとの勘定科目と問題がまとまっている。問題を足すときはここに追記する。

## デプロイ

`main` ブランチに push すると Vercel が自動でデプロイする。
